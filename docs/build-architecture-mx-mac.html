Omarchy MX Mac — build architecture

Three repositories build one release. omarchy-pkgs produces signed aarch64 packages, omarchy-iso bakes them into a sealed OS payload, and omarchy-mx-mac wraps that payload in a notarized macOS installer published to Cloudflare R2. The dashed lines are the seams: the exact files where one repository pins another.
